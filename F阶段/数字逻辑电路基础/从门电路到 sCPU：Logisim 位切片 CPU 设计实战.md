- # F阶段学习小结（sCPU与数字逻辑设计）

  ## 一、数字电路基础与Logisim避坑指南
  1. **多路选择器（MUX / 多路复用器）**
     - 本质是“数据岔路口”，通过选择端（Select）决定输出哪一路输入。
     - 数据位宽（Data Bits）决定单根线能传多少位数据；选择位（Select Bits）决定有 \(2^{\text{Select Bits}}\) 个输入端口。
     - **注意事项**：顶部的EN使能端如果不用，应在属性中取消勾选（Enable）或接常数1，否则会输出悬空（蓝线）；空闲的输入端口必须接常数0，否则选中时会报红或导致震荡。
  2. **寄存器与D触发器**
     - **R端（异步复位）**：绝对不能接时钟信号，否则会导致寄存器一直处于清零状态无法输出。必须接常数0。
     - **WE/EN端（写使能）**：用于控制何时允许写入，需配合全局时钟使用。
     - **初值处理**：电路刚上电时寄存器处于红色未知态，需通过复位(R)或手动初值（Constant）打破死锁。
  3. **分线器（Splitter）与比较器（Comparator）**
     - 分线器用于将总线拆分为单根细线，或反接将细线拼成总线。必须精确配置`Starting Location`（起始位置）和`Bits`（位宽），否则输出端会报红。
     - 比较器可同时输出`=`、`>`、`<`信号，常用于条件跳转和状态判断。
  4. **时钟与信号状态**
     - 时钟（Clock）是时序电路的“心跳”，用于同步更新寄存器；单步调试用Ctrl+T或手动脉冲，自动运行需调频率。
     - 红色导线 = 位宽冲突或信号短路（多个输出端直接相连）；蓝色导线 = 悬空（浮空/高阻态）；黑色 = 无信号；绿色 = 正常。

  ## 二、存储器与寄存器堆（GPR）设计
  1. **ROM与RAM的结构差异**
     - ROM：存储固定数据，底层可由MUX阵列或“译码器+与门或门交叉阵列”构成。数据在编辑器修改后必须先【保存】再【关闭】。
     - RAM：与ROM读取结构一致，但加入了数据输入端（D）和写使能（WE/EN），依靠D触发器和时钟实现动态读写。
  2. **多位标准GPR vs 位切片（Bit-sliced）架构**
     - **标准GPR**：数据总线为一根整体粗线。写入时通过5-32译码器选中唯一寄存器，一次性并行写入全部数据；读取时通过32选1 MUX输出完整的多位数据。0号寄存器（x0）恒为0，其写使能线必须悬空。
     - **位切片架构**：将N位寄存器拆分为N个1位切片，通过分线器将数据拆分，控制信号（如读写地址）广播给所有切片。写使能需配合逻辑门（如与门）在切片内部或外部进行局部译码。物理底层更直观，但Logisim连线繁琐。

  ## 三、CPU数据通路与指令执行设计
  1. **sCPU核心设计流程（取指-译码-执行-写回）**
     - **取指（Fetch）**：PC指针 -> ROM地址 -> 读出指令（8位/32位） -> 分线器拆分（Opcode、立即数、寄存器地址等）。
     - **译码（Decode）**：通过2-4译码器解析Opcode，生成`sel_li`、`sel_add`、`sel_bner`等控制信号。
     - **执行（Execute）**：ALU负责加法运算；读端口MUX负责根据rs1/rs2读出两个操作数。
     - **写回（Write Back）**：通过MUX选择将“ALU计算结果”或“立即数”写回目标寄存器（rd），同时根据指令类型控制写使能（we）。
  2. **PC更新与跳转逻辑**
     - **PC计算**：PC = PC + 1（自定义sISA）或 PC = PC + 4（RISC-V 32位指令，对齐到4字节）。
     - **跳转实现**：在PC更新前加一个2选1 MUX。0号口接跳转地址，1号口接PC+1。选择端接比较器的`=`输出。当条件成立（或失败）时，MUX选择对应目标，实现条件跳转（bner）。
  3. **指令编码与扩展**
     - 自定义ISA时，需统一定义指令格式（如高2位Opcode + 2位rs1 + 2位rs2 + 2位rd/立即数）。
     - 通过修改ROM数据（机器码），无需更改硬件连线，即可让CPU执行不同的程序（存储程序思想）。
     - 扩展功能（如`out rs`）只需增加译码信号并连接输出数码管（Hex Digit Display），同时确保该指令下写使能无效。

  ## 四、从状态机视角理解软硬件映射
  - **C程序、ISA、CPU电路三者的状态机等价性**：
    - 编译器将C状态机（{PC, V}）翻译为ISA状态机（{PC, R, M}）。
    - CPU设计就是用数字电路（时序逻辑实现状态/寄存器，组合逻辑实现状态转移规则/指令功能）去实现ISA状态机。
    - 执行一条C语句后的状态，与执行编译后的指令序列后的状态，在语义上等价。
  - **硬件底层真相**：无论是标准GPR还是位切片，最终综合工具都会将其映射为寄存器、MUX、译码器组成的物理电路。在后续RTL代码阶段（Verilog/Chisel），只需使用高级描述（如 `gpr(rd) := wdata`），综合工具会自动完成0号寄存器保护、进位链、布线等底层优化。

  ## 五、关键注意事项与调试经验总结
  1. **杜绝短路与悬空**：同一节点不可有两个输出源直接相连；避免输入引脚悬空，尽量接常数0或常量。
  2. **位宽严格匹配**：4位数据不能直接连1位引脚，必须通过分线器（Splitter）或位扩展器（Bit Extender）。
  3. **区分时序与组合逻辑**：寄存器更新必须依靠时钟边沿（边沿触发）；组合逻辑（MUX、加法器、比较器）的输出随输入即时变化。
  4. **谨慎使用R端与EN端**：R端接错会导致数据被瞬间抹除；EN端配置错误会导致寄存器无法写入或全量覆盖。
  5. **分线器是双刃剑**：用对能大幅精简总线连线，用错会导致位序颠倒、数据错位或直接爆红。
