# F阶段学习小结：minirv 单周期 RISC-V 处理器设计

## 一、RISC-V 指令集基础

### 1. 寄存器与状态
- RV32I 中 XLEN=32，PC 为 32 位，通用寄存器 GPR 共 32 个（x0~x31），每个 32 位。
- `x0` 是硬连线零寄存器：读恒为 0，写操作被忽略。
- 寄存器地址为 5 位，因为 2^5=32。
- 指令长度固定 32 位，指令地址按 4 字节对齐，PC 最低两位恒为 0。

### 2. 指令格式
- 基础格式：R/I/S/B/U/J。
- 所有格式中 `rs1`、`rs2`、`rd` 位置固定，便于译码。
- 关键字段：
  - `opcode`：`[6:0]`
  - `rd`：`[11:7]`
  - `funct3`：`[14:12]`
  - `rs1`：`[19:15]`
  - `rs2`：`[24:20]`
  - `funct7`：`[31:25]`

### 3. 立即数编码与扩展
- I 型立即数：`[31:20]`，需符号扩展。
- S 型立即数：高 7 位 `[31:25]` + 低 5 位 `[11:7]`，拼接后符号扩展。
- B 型立即数：`[31]`、`[7]`、`[30:25]`、`[11:8]`，最低位固定 0，拼接后符号扩展并左移 1 位。
- U 型立即数：`[31:12]`，用于 `lui`，左移 12 位。
- J 型立即数：`[31]`、`[19:12]`、`[20]`、`[30:21]`，最低位固定 0。

### 4. 指令功能要点
- `addi`：`rd = rs1 + 符号扩展(imm)`。
- `lui`：`rd = imm[31:12] << 12`。
- `add`：`rd = rs1 + rs2`。
- `slli`：`rd = rs1 << shamt`，`shamt` 取 `[24:20]` 低 5 位。
- `bne`：若 `rs1 != rs2`，则 `PC = PC + 符号扩展(B型imm)`，否则 `PC += 4`。
- `jalr`：`t = rs1 + 符号扩展(imm)`，`t` 最低位清零，`rd = PC+4`，`PC = t`。
- `lw`：`rd = 内存[rs1 + imm]`，读 32 位。
- `sw`：`内存[rs1 + imm] = rs2`，写 32 位。
- `lbu`：`rd = 零扩展(内存字节[rs1 + imm])`。
- `sb`：`内存字节[rs1 + imm] = rs2[7:0]`。

## 二、单周期 CPU 数据通路

### 1. 取指阶段
- PC 输出经分线器截取 `[N:2]` 后送入指令 ROM。
- ROM 输出 32 位指令，经指令分线器拆出各字段。
- PC 更新由 PC MUX 控制，来源包括：
  - `PC + 4`：顺序执行
  - `ALU` 计算的 `jalr` 目标
  - `ALU` 计算的 `bne` 目标

### 2. 译码与控制
- 用 7 位比较器判断 `opcode` 大类。
- 用 `funct3` 区分同 `opcode` 下的不同指令，如 `addi` 与 `slli`。
- 用优先编码器统一管理写回数据源选择。
- 控制信号必须精确到每条指令，不能混淆。

### 3. 执行阶段
- ALU 输入 A：`rs1` 或 `PC`，由 MUX 选择。
- ALU 输入 B：`rs2`、I 型立即数、B 型立即数，由 MUX 选择。
- ALU 内部包含加法器、减法器、移位器，结果经 MUX 输出。
- `slli` 必须选通移位器，`shamt` 来自 `[24:20]`。
- `bne` 需要比较 `rs1` 与 `rs2`，可用减法判零或比较器实现。

### 4. 访存阶段
- 数据 RAM 地址来自 ALU 输出，需截取 `[N:2]` 映射为字地址。
- 读使能 `OE` 可常置 1，用写使能 `WE` 和字节使能 `BE` 控制写入。
- `sw`：`BE0~BE3` 全为 1。
- `sb`：根据地址最低两位，仅使能对应 1 个字节。
- `lbu` 零扩展，`lb` 符号扩展，二者不可混淆。

### 5. 写回阶段
- GPR 写回 MUX 选择数据源：
  - ALU 结果：`addi`、`add`、`lui`、`slli`
  - `PC+4`：`jalr`
  - RAM 数据：`lw`、`lbu`
- GPR 写使能 `EN` 只对需要写寄存器的指令拉高。
- `sw`、`sb`、`bne` 绝对不能写 GPR。

## 三、关键模块设计要点

### 1. GPR 寄存器堆
- 5 位译码器选择 32 个寄存器。
- `x0` 的 WE 接地，输出端不接入读 MUX；读 MUX 的 0 号输入接常数 0。
- 读端口 `RD1`、`RD2` 由 `rs1`、`rs2` 直接控制。
- 地址线错位会导致“写错寄存器”或“读错寄存器”。

### 2. ALU
- 加、减、移位、逻辑运算需通过 MUX 选择输出。
- `is_slli` 控制移位器通道。
- `is_use_rs2` 控制 ALU 输入 B 选 `rs2`，`add` 和 `bne` 都需要。
- 比较结果 `Zero` 用于 `bne` 判断。

### 3. PC 更新 MUX
- 8 选 1 MUX 仅用 3 个输入即可：
  - `000`：`PC+4`
  - `001`：`jalr` 目标
  - `010`：`bne` 目标
- 控制码可直接由：
  - `S2 = 0`
  - `S1 = bne_taken`
  - `S0 = is_jalr`
- `bne_taken = is_bne AND Not_Zero`。

### 4. VGA MMIO 外设
- 显存地址范围：`[0x20000000, 0x20040000)`。
- 地址译码器需用无符号比较：
  - `addr >= 0x20000000`
  - `addr < 0x20040000`
- 产生 `isVGA`，再取反得到 `isMem`。
- 写使能隔离：
  - `VGA_WE = isVGA AND is_store`
  - `RAM_WE = isMem AND is_store`
- `RGB Video` 数据输入接 GPR 写数据总线的低 24 位。
- 颜色模式选 `888 RGB (24 bit)`。
- X 坐标取地址 `[9:2]`，Y 坐标取地址 `[17:10]`。

## 四、Logisim 调试方法

- 用 `Splitter` 分线器直接观察指令字段，例如 `[11:7]` 看 `rd`。
- 单步 `Tick Once` 比自动时钟更容易定位问题。
- 修改 ROM、RAM 或电路后，必须按 `Reset`，否则仿真状态残留。
- 悬停信号线看数值，比猜测可靠。
- 线全红通常表示总线冲突或信号同时驱动。
- `u` 表示未定义或悬空，常见于 MUX 输入未接、译码器输出悬空。
- 跑长程序前删除多余 `Output Pin` 和探针，可大幅提速。
- 周期计数器可帮助判断程序是否跑完指定周期。
- 不同指令格式不能共用同一个 `Merger` 拼接立即数。
- 优先编码器端口不足时，可用 MUX 做隔离，或扩展输入位宽。

## 五、常见坑与注意事项

1. **机器码必须逐位核对**  
   `rd`、`rs1`、`rs2`、`funct3`、`opcode` 容易混淆。一条机器码错误会导致整条指令行为完全改变。

2. **单条指令测试通过，不代表组合测试通过**  
   组合测试可能暴露寄存器冲突、数据依赖、写使能隔离等问题。

3. **写使能必须严格隔离**  
   `sw`、`sb`、`bne` 不能写 GPR；`lw`、`lbu` 不能写 RAM；VGA 与普通 RAM 的 WE 必须互斥。

4. **立即数拼接与扩展不能出错**  
   S 型、B 型立即数分散在指令中，拼接后还要符号扩展，B 型还要左移 1 位。

5. **ALU 输入选择要正确**  
   `addi` 选立即数，`add` 选 `rs2`，`slli` 选 `shamt`，`bne` 选 `rs2` 并比较。

6. **PC 更新来源不能混淆**  
   `PC+4`、`jalr` 目标、`bne` 目标分别对应不同控制码，不能接错。

7. **RAM 地址位宽要足够**  
   跑 `vga.hex` 时，显存需要覆盖 `0x20000000` 以上地址，RAM 位宽不足会导致数据丢失或回绕，屏幕显示异常。

8. **x0 必须恒为 0**  
   写 x0 被忽略，读 x0 返回 0；读 MUX 的 0 号输入应接常数 0，而不是物理寄存器。

9. **时序是同步电路的核心**  
   寄存器在时钟上升沿锁存，当前周期算出的值下一周期才生效。

10. **先验证机器码，再怀疑硬件**  
    在复杂调试中，错误机器码会伪装成硬件故障；用分线器和单步执行可快速区分问题来源。
