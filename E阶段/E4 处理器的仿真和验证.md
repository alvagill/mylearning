# E4

## 1. 开发环境
- WSL + VS Code + Verilator（源码安装 5.x 版本）+ NVBoard + GTKWave
- **注意事项**：
  - Verilator 编译用 `-j 1`，避免 WSL 幽灵缓存
  - 不要在 `.bashrc` 里乱设 `VERILATOR_ROOT`
  - 不要用 `usleep` 拖慢 NVBoard 主循环（会触发节流机制导致黑屏卡死）
  - 时钟只能有一个来源：要么 C++ 手动翻转，要么 `.nxdc` 绑物理引脚，不能同时

## 2. NVBoard 数字电路实验
- **`.nxdc` 引脚约束**：`top=模块名` + `信号 引脚组`，引脚名必须严格查官方示例
- **常用外设**：
  - SW（16 位开关组）、LD（16 位 LED 组）、BTN（5 个按钮）
  - SEG（七段数码管，低电平有效）、VGA（视频输出）、PS2（键盘）
- **七段数码管**：低电平有效（0 亮 1 灭），段序必须与官方一致

## 3. 核心电路设计
- **优先编码器**：优先级判断必须用 if-else 链或状态位，不能用 MuxKey
- **ALU**：多功能运算 + MUX 选择输出，不是单一加法器
- **LFSR**：异或反馈、全零死锁保护（复位加载非零初值）
- **PS/2 键盘**：11 位帧（起始位 + 8 位数据 + 奇校验 + 停止位），F0 是松键前缀，后跟回显键码
- **VGA**：640×480@60Hz，水平 800 周期 / 垂直 525 行，valid 只用于可见区

## 4. 存储器与数据通路
- **ROM**（指令）和 **RAM**（数据）分离，哈佛结构
- **字节编址**：内存最小单位是 1 字节，32 位数据占 4 个连续字节地址
- **小端序**：低字节放低地址
- **地址对齐**：RISC-V 指令 2 字节对齐，地址最低位恒为 0

## 5. RISC-V 指令格式
- **6 种格式**：R / I / S / B / U / J
- **位域分布**：
  - `opcode[6:0]`（永远最低 7 位）
  - `rd[11:7]`、`funct3[14:12]`、`rs1[19:15]`、`rs2[24:20]`、`funct7[31:25]`
- **立即数拼接**：
  - I 型：连续 `[31:20]`，直接右移符号扩展
  - S 型：拆成 `[31:25]` + `[11:7]`，需拼接 + 符号扩展
  - B/J 型：位错位分散，需特殊拼接
  - U 型：`[31:12]` 直接左移 12 位，无需符号扩展
- **关键指令语义**：
  - ADDI/ADD/LUI：运算类
  - LW/LB/SW/SB：访存类，LB 需符号扩展
  - JALR：`rd = pc+4`，`pc = (rs1+imm) & ~1`

## 6. DPI-C 机制
- Verilog 与 C/C++ 之间的函数调用桥
- **Verilog 侧**：`import "DPI-C" function void f();`
- **C 侧**：`extern "C" void f() { ... }`
- 用途：硬件主动通知软件（如 ebreak 停止仿真）

## 7. DiffTest 原理
- 参考模型（sEMU/NEMU）+ 被测硬件（sCPU/NPC）+ 逐拍比对
- **比对内容**：PC + 所有 GPR
- **发现不一致**：打印"第几拍、哪个寄存器、两边值"，立即停止

# 阶段二：从 sCPU 到 DiffTest 的实战知识

## 1. 模块化设计原则
- **接口先行**：先画数据通路图 + 定义接口信号，再分头写实现
- **能合并的合并**：ALU 一条加法通路服务 ADDI/LW/SW/JALR
- **必须区分的区分**：控制信号（reg_write、mem_read、pc_src）必须独立
- **模块化好处**：ALU、decoder、regfile 可独立测试，互不干扰

## 2. 数据通路核心连线
- **PC 更新**：`next_pc = halt ? pc : pc_src ? (alu_result & ~1) : (pc + 4)`
- **写回数据 MUX**：
  - JALR → `pc + 4`（返回地址）
  - LOAD → `mem_rdata`（内存数据）
  - 其他 → `alu_result`（ALU 结果）
- **RAM 写数据**：来自 `rdata2`（rs2），不是地址
- **RAM 地址**：来自 `alu_result`
- **立即数 MUX**：按 `imm_sel` 选 I/S/U 型

## 3. 控制信号清单
| 信号        | 作用                          |
| :---------- | :---------------------------- |
| `alu_op`    | ALU 做什么运算                |
| `mem_read`  | LOAD 时拉高，控制写回 MUX     |
| `mem_write` | STORE 时拉高，控制 RAM 写使能 |
| `reg_write` | 是否写回寄存器                |
| `pc_src`    | 是否跳转（JALR）              |
| `imm_sel`   | 选哪种立即数格式              |
| `halt`      | EBREAK 后冻结 PC              |

## 4. 关键 Bug 与教训
- **编码类**：ADDI 的 rs/rd 字段位置弄反，写入 r0 被丢弃
  - 教训：手写机器码必须回算验证
- **时序类**：pc 更新和取指在同一拍，sCPU 比 sEMU 快一拍
  - 教训：加 instr_reg 锁存，让取指-执行-pc 更新分步
- **状态机类**：忘记 F0 后紧跟的回显键码，松开键被误判为新按下
  - 教训：引入 f0_seen 状态机区分"松键回显"和"新按下"
- **端口类**：`.nxdc` 里 clk 绑物理开关 + C++ 手动翻转 → 抢时钟
  - 教训：时钟只能有一个来源
- **模块名类**：RAM.v 里模块名 `ram` vs 例化 `RAM` 大小写不匹配
  - 教训：Verilog 大小写敏感

## 5. 调试方法论
- **小步快跑**：EBREAK → ADDI → ADD → LW/SW → LB/SB/JALR
- **每步 DiffTest**：全绿再进下一阶段
- **单模块单测**：先写 test_alu、test_semu 单独验证
- **报错信息完整**：周期 + PC + 所有 GPR 快照
- **三件套**：RTFM（读手册）+ STFW（搜索）+ DiffTest（对比）

## 6. 存储与访存细节
- **内存用 `uint8_t M[65536]`**：字节编址，1 字节一个格子
- **LW 拼 4 字节**：`M[a] | (M[a+1]<<8) | (M[a+2]<<16) | (M[a+3]<<24)`
- **SW 拆 4 字节**：分别写入 `M[a]` 到 `M[a+3]`
- **LB 符号扩展**：`(int32_t)(int8_t)M[addr]`
- **S 型立即数符号扩展**：`(imm & 0x800) ? (imm | 0xFFFFF000) : imm`

## 7. 设计心法
- **寄存器 = 盒子**（快但少），**内存 = 草稿纸**（慢但大）
- **算术指令**操作盒子，**访存指令**在盒子和草稿纸之间搬数据
- **跳转指令**改变"下一条读哪里"
- **ALU 不知道自己在算什么指令**，只认 `alu_op`
- **Decoder 是发令官**，控制所有 MUX
- **顶层是连线**，把模块和 MUX 连起来
