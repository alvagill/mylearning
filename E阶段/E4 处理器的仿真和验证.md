# E4

## 1. 开发环境
- WSL + VS Code + Verilator（源码安装 5.x 版本）+ NVBoard + GTKWave
- **注意事项**：
  - Verilator 编译用 `-j 1`，避免 WSL 幽灵缓存
  - 不要在 `.bashrc` 里乱设 `VERILATOR_ROOT`
  - 不要用 `usleep` 拖慢 NVBoard 主循环（会触发节流机制导致黑屏卡死）
  - 时钟只能有一个来源：要么 C++ 手动翻转，要么 `.nxdc` 绑物理引脚，不能同时

## 2. NVBoard 数字电路实验
- **`.nxdc` 引脚约束**：`top=模块名` + `信号 引脚组`，引脚名必须严格查官方示例
- **常用外设**：
  - SW（16 位开关组）、LD（16 位 LED 组）、BTN（5 个按钮）
  - SEG（七段数码管，低电平有效）、VGA（视频输出）、PS2（键盘）
- **七段数码管**：低电平有效（0 亮 1 灭），段序必须与官方一致

## 3. 核心电路设计
- **优先编码器**：优先级判断必须用 if-else 链或状态位，不能用 MuxKey
- **ALU**：多功能运算 + MUX 选择输出，不是单一加法器
- **LFSR**：异或反馈、全零死锁保护（复位加载非零初值）
- **PS/2 键盘**：11 位帧（起始位 + 8 位数据 + 奇校验 + 停止位），F0 是松键前缀，后跟回显键码
- **VGA**：640×480@60Hz，水平 800 周期 / 垂直 525 行，valid 只用于可见区

## 4. 存储器与数据通路
- **ROM**（指令）和 **RAM**（数据）分离，哈佛结构
- **字节编址**：内存最小单位是 1 字节，32 位数据占 4 个连续字节地址
- **小端序**：低字节放低地址
- **地址对齐**：RISC-V 指令 2 字节对齐，地址最低位恒为 0

## 5. RISC-V 指令格式
- **6 种格式**：R / I / S / B / U / J
- **位域分布**：
  - `opcode[6:0]`（永远最低 7 位）
  - `rd[11:7]`、`funct3[14:12]`、`rs1[19:15]`、`rs2[24:20]`、`funct7[31:25]`
- **立即数拼接**：
  - I 型：连续 `[31:20]`，直接右移符号扩展
  - S 型：拆成 `[31:25]` + `[11:7]`，需拼接 + 符号扩展
  - B/J 型：位错位分散，需特殊拼接
  - U 型：`[31:12]` 直接左移 12 位，无需符号扩展
- **关键指令语义**：
  - ADDI/ADD/LUI：运算类
  - LW/LB/SW/SB：访存类，LB 需符号扩展
  - JALR：`rd = pc+4`，`pc = (rs1+imm) & ~1`

## 6. DPI-C 机制
- Verilog 与 C/C++ 之间的函数调用桥
- **Verilog 侧**：`import "DPI-C" function void f();`
- **C 侧**：`extern "C" void f() { ... }`
- 用途：硬件主动通知软件（如 ebreak 停止仿真）

## 7. DiffTest 原理
- 参考模型（sEMU/NEMU）+ 被测硬件（sCPU/NPC）+ 逐拍比对
- **比对内容**：PC + 所有 GPR
- **发现不一致**：打印"第几拍、哪个寄存器、两边值"，立即停止
