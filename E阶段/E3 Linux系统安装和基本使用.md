# 一生一芯 E阶段 核心知识点学习笔记

## 一、 Linux 与 Shell 基础

### 1. 文件系统与路径
*   **目录结构**：`/` 是根目录；`~` 是用户主目录（`/home/用户名`）；`.` 是当前目录；`..` 是上级目录。
*   **常用命令**：`pwd`（当前路径）、`ls`（列出文件，`-a` 看隐藏，`-l` 看详情）、`cd`（切换目录）、`mkdir`（建目录）、`rm`（删除）、`mv`（移动/重命名）、`cp`（复制）。
*   **权限**：`rwx`（读、写、执行）。`chmod +x 文件名` 赋予执行权限（脚本必须加）。文件夹必须用 `rm -r` 删除。

### 2. 输入输出与管道
*   **重定向**：`>`（覆盖写入）、`>>`（追加写入）、`2>&1`（将标准错误也写入文件）。
*   **管道 `|`**：将前一个命令的输出作为后一个命令的输入。
    *   例如：`find . -name "*.html" | xargs zip html.zip`（按行处理，防止空格断开）。
*   **环境变量**：`export 变量名=值`（临时生效）；写入 `~/.bashrc` 后 `source ~/.bashrc`（永久生效）。引用变量用 `$变量名`。
*   **退出码（$?）**：上一个命令成功返回 `0`，失败返回非 `0`。
*   **短路运算**：`&&`（前面成功才执行后面）；`||`（前面失败才执行后面）；`;`（无论前面如何都执行）。

### 3. Git 版本控制
*   **基础流程**：`git init`（初始化） -> `git add .`（暂存） -> `git commit -m "说明"`（提交）。
*   **分支**：`git checkout -b pa0`（创建并切换新分支）；`git branch`（查看分支）；`git checkout master`（切换回主分支）。
*   **远程操作**：`git clone`（拉取代码）、`git push`（推送代码）。
*   **注意**：必须配置 `user.name` 和 `user.email` 才能提交。

## 二、 C 语言进阶（核心难点）

### 1. 内存管理（栈 vs 堆）
*   **栈（Stack）**：函数内自动创建的局部变量，函数结束自动销毁，速度快，容量小。
*   **堆（Heap）**：通过 `malloc`/`calloc` 主动申请，必须手动用 `free` 释放（否则内存泄漏），速度慢，容量大。
*   **`malloc` vs `calloc`**：`malloc` 不初始化内存；`calloc` 初始化并清零。
*   **内存所有权**：谁申请（malloc），谁负责释放（free）。释放后指针应置为 `NULL`，防止悬空指针。

### 2. 指针与数组
*   **数组名**：本质是指向第一个元素的指针（`int a[]` 等价于 `int *a`）。
*   **地址与值**：`arr[i]` 等价于 `*(arr + i)`（去地址取值）。
*   **二级指针 `char **`**：存放“指针的指针”，常用来表示字符串数组（如 `main` 的 `argv`）。
*   **指针运算**：`ptr + 1` 不是加 1 字节，而是加整个类型的大小（如 `int*` 加 4 字节）。

### 3. 结构体与函数指针
*   **`struct`**：将不同类型的数据打包在一起。
*   **`.` vs `->`**：普通变量用 `.`（如 `p.age`）；指针变量用 `->`（如 `p->age`，等价于 `(*p).age`）。
*   **嵌套结构体**：模拟“基类和子类”的继承关系（把父结构体放在子结构体的第一个位置）。
*   **函数指针**：用于“回调”和“多态”。声明：`int (*cmp)(int a, int b)`；用 `typedef` 简写：`typedef int (*compare_cb)(int a, int b)`。
*   **`void *self`**：模仿面向对象中的 `this` 指针。

### 4. 字符串与输入输出
*   **字符串本质**：以 `\0` 结尾的字符数组。数组必须留出 1 个字节放 `\0`。
*   **`strdup`**：在堆上复制一份字符串（深拷贝），必须 `free`。
*   **`strncpy`**：限制长度的复制，但是**不会自动补 `\0`**（容易导致乱码）。
*   **`fgets` vs `fscanf`**：`fgets` 读一整行（处理空格安全）；`fscanf` 读格式化数字。若先 `fscanf` 后 `fgets`，必须用 `getchar()` 吃掉残留的换行符。

### 5. 宏与防御性编程
*   **宏定义 `#define`**：纯文本替换，不检查类型。
*   **`##__VA_ARGS__`**：可变参数宏，用来处理 `printf` 类型的不定长参数。
*   **防御性编程**：使用 `check` 宏（检查失败 `goto error`）统一清理内存、报错并退出，防止程序直接“段错误”崩溃。
*   **`assert`**：断言，假设条件一定成立，若不成立直接终止程序（用于测试）。

## 三、 编译与构建系统

### 1. GCC 编译流程
*   **万能公式**：`gcc -g -Wall source.c -o program`
    *   `-g`（必须加！生成调试信息，供 GDB 使用）。
    *   `-Wall`（开启所有警告）。
    *   `-o` 指定输出文件名（不加默认生成 `a.out`）。
*   **运行**：`./program`（注意：千万不能运行 `.c` 文件，只能运行无后缀的可执行文件）。

### 2. Makefile 核心逻辑
*   **格式**：`目标: 依赖` -> 下一行按 `Tab` 键写命令。
*   **变量**：`CFLAGS=-g -Wall`，引用时用 `$(CFLAGS)`。
*   **隐式规则**：只敲 `make ex1`，Make 会自动查找 `ex1.c` 并编译。
*   **默认目标 `all`**：排在第一位的目标，敲 `make` 时自动执行。
*   **`clean`**：清理编译产物（如 `rm -rf build`）。
*   **警告**：命令前必须是 **Tab 键**，不能是空格，否则报 `missing separator`。

### 3. 静态库与动态库
*   **静态库（.a）**：编译时直接复制进程序（体积大，独立运行）。用 `ar rcs` 打包。
*   **动态库（.so）**：运行时加载（体积小，依赖环境）。用 `-shared` 生成。
*   **链接**：`gcc main.c -ldl`（链接系统库）。用 `-L` 指路，`-l` 指库名。
*   **`dlopen`/`dlsym`**：运行时手动打开动态库并获取函数地址（黑魔法）。

## 四、 调试与测试

### 1. GDB 调试
*   **启动**：`gdb -tui ./program`（TUI 模式可看代码）。
*   **断点**：`break main`（或 `b 10` 在第10行）。
*   **运行**：`run`（全速到断点）。
*   **单步**：`next`（下一步，跳过函数）；`step`（步入函数）。
*   **查看**：`print 变量名` 或 `info locals`（查看所有变量）。
*   **持续显示**：`display 变量名`（每次单步自动打印）。
*   **继续**：`continue` 到下一断点。退出用 `quit`。

### 2. Valgrind 内存检查
*   **用法**：`valgrind --leak-check=full ./program`。
*   **看关键词**：
    *   `definitely lost`：内存泄漏（申请了没 free）。
    *   `Invalid read/write`：越界访问（指针访问了不属于自己的地址）。
*   **注意**：会大大拖慢程序运行速度，只在排查问题时使用。

### 3. 单元测试
*   **原理**：用 `assert` 断言函数返回值和逻辑是否正确。
*   **自动化**：写一个 `tests_xxx.c`，用 Makefile 的 `make test` 一键运行，全绿（PASSED）则代码正确。

## 五、 算法与数据结构（纯 C 实现）

### 1. 链表（双向）
*   包含 `value`、`next`、`prev` 三个指针。
*   `List_push` 尾部插入，`List_pop` 尾部取出，`List_unshift` 头部插入，`List_shift` 头部取出。
*   **指针交换**：修改前后节点的 `next` 和 `prev` 指向，防止断链。

### 2. 排序算法
*   **冒泡排序**：嵌套循环，相邻比较，大的往后浮。时间复杂度 \(O(N^2)\)。
*   **归并排序**：分治思想。先递归拆分数组到最小（1个元素），再合并有序数组。需要用 `malloc` 申请临时空间，记得 `free`。时间复杂度 \(O(N \log N)\)。
