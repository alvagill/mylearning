# E5

## 1. 模块化设计原则
- **接口先行**：先画数据通路图 + 定义接口信号，再分头写实现
- **能合并的合并**：ALU 一条加法通路服务 ADDI/LW/SW/JALR
- **必须区分的区分**：控制信号（reg_write、mem_read、pc_src）必须独立
- **模块化好处**：ALU、decoder、regfile 可独立测试，互不干扰

## 2. 数据通路核心连线
- **PC 更新**：`next_pc = halt ? pc : pc_src ? (alu_result & ~1) : (pc + 4)`
- **写回数据 MUX**：
  - JALR → `pc + 4`（返回地址）
  - LOAD → `mem_rdata`（内存数据）
  - 其他 → `alu_result`（ALU 结果）
- **RAM 写数据**：来自 `rdata2`（rs2），不是地址
- **RAM 地址**：来自 `alu_result`
- **立即数 MUX**：按 `imm_sel` 选 I/S/U 型

## 3. 控制信号清单
| 信号        | 作用                          |
| :---------- | :---------------------------- |
| `alu_op`    | ALU 做什么运算                |
| `mem_read`  | LOAD 时拉高，控制写回 MUX     |
| `mem_write` | STORE 时拉高，控制 RAM 写使能 |
| `reg_write` | 是否写回寄存器                |
| `pc_src`    | 是否跳转（JALR）              |
| `imm_sel`   | 选哪种立即数格式              |
| `halt`      | EBREAK 后冻结 PC              |

## 4. 关键 Bug 与教训
- **编码类**：ADDI 的 rs/rd 字段位置弄反，写入 r0 被丢弃
  - 教训：手写机器码必须回算验证
- **时序类**：pc 更新和取指在同一拍，sCPU 比 sEMU 快一拍
  - 教训：加 instr_reg 锁存，让取指-执行-pc 更新分步
- **状态机类**：忘记 F0 后紧跟的回显键码，松开键被误判为新按下
  - 教训：引入 f0_seen 状态机区分"松键回显"和"新按下"
- **端口类**：`.nxdc` 里 clk 绑物理开关 + C++ 手动翻转 → 抢时钟
  - 教训：时钟只能有一个来源
- **模块名类**：RAM.v 里模块名 `ram` vs 例化 `RAM` 大小写不匹配
  - 教训：Verilog 大小写敏感

## 5. 调试方法论
- **小步快跑**：EBREAK → ADDI → ADD → LW/SW → LB/SB/JALR
- **每步 DiffTest**：全绿再进下一阶段
- **单模块单测**：先写 test_alu、test_semu 单独验证
- **报错信息完整**：周期 + PC + 所有 GPR 快照
- **三件套**：RTFM（读手册）+ STFW（搜索）+ DiffTest（对比）

## 6. 存储与访存细节
- **内存用 `uint8_t M[65536]`**：字节编址，1 字节一个格子
- **LW 拼 4 字节**：`M[a] | (M[a+1]<<8) | (M[a+2]<<16) | (M[a+3]<<24)`
- **SW 拆 4 字节**：分别写入 `M[a]` 到 `M[a+3]`
- **LB 符号扩展**：`(int32_t)(int8_t)M[addr]`
- **S 型立即数符号扩展**：`(imm & 0x800) ? (imm | 0xFFFFF000) : imm`

## 7. 设计心法
- **寄存器 = 盒子**（快但少），**内存 = 草稿纸**（慢但大）
- **算术指令**操作盒子，**访存指令**在盒子和草稿纸之间搬数据
- **跳转指令**改变"下一条读哪里"
- **ALU 不知道自己在算什么指令**，只认 `alu_op`
- **Decoder 是发令官**，控制所有 MUX
- **顶层是连线**，把模块和 MUX 连起来
